# peachworks Official Website

Official peachworks website, designed with minimalist but tactical UI.

## Overview

This repo features the front-end for my visual portfolio. Inspired by a 007/James Bond 2000s era computer, this is designed
with certain elements in mind to capture that feel. Therefore, it is observed through design choices such as monospace typography,
a simulated scan overlay, and live data polling.

## Stack

**Structure** = HTML5
**Styling** = Tailwind CSS & Custom CSS3
**Logic** = Vanilla JavaScript
**Typography** = Courtesy of Google Fonts [Iosevka Charon Mono] / (https://typeof.net/Iosevka/)
**Icons** = Courtesy of Phosphor Icons / (https://phosphoricons.com/)
